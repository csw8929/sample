📱 우리 가족 앱 사용 설명서

민서 스토어에 있는 앱들이 각각 무엇을 하는 앱인지, 어떻게 쓰는지 정리했습니다.

설치 / 업데이트 방법

  1. MinseoStore 앱을 먼저 설치합니다 (개인용 앱 스토어).
  2. MinseoStore를 열면 아래 앱들이 카드 형태로 목록에 뜹니다.
  3. 설치되어 있지 않은 앱은 "설치", 새 버전이 나온 앱은 "업데이트" 버튼이 보입니다.
  4. 버튼을 누르면 자동으로 다운로드 후 설치가 진행됩니다.

앱 목록

  • Minseo — 계정 관리
  • 삿치 — 비디오 플레이어
  • Minseo3 — 전자책 리더
  • SubFeed — 유튜브 피드
  • Minseo5 — 용돈 기록
  • Minseo6 — 가족 위치 공유
  • Minseo7 — 잠금해제 메모
  • Minseo8 — 가족 구매목록
  • Minseo9 — 버스 도착 알림
  • MyCard — 카드 사용내역
  • MinseoStore — 앱 스토어

Minseo

계정 관리

아이디 · 비밀번호 · 메모를 모아두는 저장소

주요 기능

  • 서비스별 이름 / 아이디 / 비밀번호 / 메모(정보)를 한 곳에 저장
  • 전체 목록 보기 (이름 기준 오름차순/내림차순 정렬)
  • 모든 항목을 대상으로 한 번에 검색 (이름/아이디/비번/메모 어디든 일치하면 검색됨)
  • 전체 내용을 JSON 형태로 내보내기 → 복사해서 백업 가능

사용법

  1. 메인 화면에서 목록보기를 눌러 저장된 계정들을 확인합니다.
  2. 추가로 새 계정을 등록하고, 목록에서 항목을 눌러 수정/삭제합니다.
  3. 검색으로 필요한 계정을 빠르게 찾습니다.
  4. 내보내기 화면에서 전체 내용을 복사해 백업해둘 수 있습니다.

삿치 (Minseo21)

비디오 플레이어

NAS 영상을 2D/3D/VR로 재생하는 플레이어

주요 기능

  • NAS(나스)에 저장된 동영상 폴더를 탐색 (에피소드 번호 자동 정렬)
  • 일반 2D 재생 + SBS 3D / VR180 / VR360 재생 지원
  • Galaxy XR 기기에서는 시네마룸(가상 영화관) 모드로 재생 가능
  • 보던 위치를 자동 저장해 다음에 열면 이어보기
  • 자막(.smi/.srt/.ass/.ssa) 및 오디오 트랙 선택, 화면 모드(가로/세로 채움) 기억
  • 재생목록 이전/다음 영상 이동, 핀치 확대·회전 잠금

사용법

  1. 앱을 열면 NAS 폴더 목록이 보입니다. 폴더 → 영상 순으로 들어갑니다.
  2. 이전에 보던 영상이 있으면 이어보기 여부를 물어봅니다.
  3. 화면을 터치하면 재생 컨트롤(자막/속도/트랙 선택 등)이 나타납니다.
  4. 3D/VR 영상은 자동 인식되며, Galaxy XR 기기에서는 전용 화면으로 전환됩니다.

Minseo3

전자책 리더

NAS에 있는 TXT 책을 읽어주는(TTS) 리더

주요 기능

  • NAS에 있는 TXT 전자책을 불러와 페이지 단위로 읽기
  • 페이지를 미리 캐시해두어 다음 페이지 전환이 빠름
  • TTS(음성으로 읽어주기) — 화면이 꺼져도 계속 재생되는 포그라운드 서비스, 잠금화면에서도 재생/정지 컨트롤 가능
  • 블루투스 이어폰/스피커 연결이 끊기면 자동으로 일시정지

사용법

  1. NAS에서 읽을 책(TXT 파일)을 선택합니다.
  2. 화면을 넘기며 읽거나, 재생 버튼을 눌러 음성으로 들을 수 있습니다.
  3. 블루투스 이어폰을 빼면 자동으로 멈추고, 다시 연결 후 이어서 재생할 수 있습니다.

SubFeed (Minseo41)

유튜브 피드

구독한 유튜브 채널을 광고 없이 보는 앱

주요 기능

  • 구독 중인 채널의 오늘 올라온 영상을 모아 광고 없이 재생
  • 기기 여러 대에서 시청 위치가 서로 동기화됨 (폰에서 보다가 태블릿에서 이어보기)
  • 구독 채널 목록을 Google Takeout 파일(subscriptions.xml)로 한 번에 가져오기, 또는 채널 URL 직접 추가

사용법

  1. 처음 설치 후 Google 계정으로 로그인합니다 (시청 위치 동기화용).
  2. 설정 화면에서 구독 채널을 가져오거나 직접 추가합니다.
  3. 홈 피드에서 오늘 올라온 영상을 골라 재생합니다.

Minseo5

용돈 기록

카드 결제 문자를 자동으로 읽어 용돈 지출을 기록

주요 기능

  • 카드 결제 문자를 앱으로 공유하면 날짜·금액·사용처를 자동으로 읽어 기록 (중복 방지)
  • 문자를 복사한 뒤 클립보드에서 붙여넣기로도 가져오기 가능
  • 직접 수동으로 지출 항목 입력도 가능
  • 월별 지출 목록, 항목을 선택해 부분 합계 확인
  • 통계 화면 — 파이 차트/막대 그래프, 카테고리별 지출 Top5
  • 전체 내용을 파일로 내보내기/가져오기 (백업)

사용법

  1. 결제 문자 메시지에서 공유하기 → Minseo5를 선택하면 자동으로 기록됩니다.
  2. 메인 화면에서 이번 달 지출 목록과 합계를 확인합니다.
  3. 통계 메뉴에서 카테고리별로 얼마나 썼는지 그래프로 확인합니다.

Minseo6

가족 위치 공유

가족 구성원의 실시간 위치를 지도에서 확인

주요 기능

  • 네이버 지도 위에 가족 구성원 위치를 실시간 마커로 표시
  • 멤버를 탭하면 현재 주소, 상태, 마지막 업데이트 시각을 카드로 확인
  • 장소 등록 — 집/회사/학원 등을 지도에서 선택하거나 현재 위치로 등록
  • 도착 알림 — 특정 멤버가 등록된 장소나 다른 멤버에게 다가오면 15/10/5/3/1분 전 + 도착 시 단계별 알림
  • 배터리 절약 모드 등으로 위치 갱신이 안 될 때 안내 메시지 제공

사용법

  1. 앱 실행 후 위치 권한을 허용합니다 (배터리 최적화 제외도 함께 설정 권장).
  2. 지도에서 가족 구성원 위치를 확인하고, 멤버를 눌러 상세 정보를 봅니다.
  3. 장소 관리에서 자주 가는 곳을 등록해두면, 그 장소로 오는 가족에게 도착 알림이 갑니다.

Minseo7

잠금해제 메모

화면 잠금을 풀 때마다 메모를 보여주는 앱

주요 기능

  • 화면 잠금을 해제하는 순간 등록해둔 메모를 오버레이로 화면에 표시
  • 메모 / 기록 두 개의 탭으로 구분 관리
  • 스와이프로 삭제(실행취소 가능) / 중요도 변경, 길게 눌러 드래그로 순서 변경
  • 메모별 글꼴, 크기, 색상 지정 가능
  • 알림 보여줄 시각 / 만료 시각 지정 가능
  • 메모를 캘린더 앱 일정으로 내보내기
  • 너무 자주 뜨지 않도록 표시 빈도 제한 설정

사용법

  1. 메모 탭에서 추가로 새 메모를 작성하고 글꼴/색/알림 시각을 지정합니다.
  2. 이후 화면 잠금을 해제할 때마다 등록된 메모가 오버레이로 나타납니다.
  3. 확인한 메모는 스와이프로 지우거나 기록 탭으로 옮길 수 있습니다.

Minseo8

가족 구매목록

사고 싶은 물건을 가족에게 링크로 요청

주요 기능

  • 가족 구성원별로 구매 희망목록 관리 (멤버 추가/수정/삭제)
  • 쇼핑 앱(쿠팡 등)에서 상품 링크를 공유하면 상품명 · 사진 · 가격이 자동으로 채워짐
  • 클립보드에 링크가 복사돼 있으면 항목 추가 시 자동으로 붙여넣기
  • 요청 버튼 — 연락처에서 가족을 선택하면 "OO 구매해주세요"라는 문자(SMS)가 링크와 함께 자동 발송

사용법

  1. 쇼핑 앱에서 사고 싶은 상품을 공유하기 → Minseo8로 보냅니다.
  2. 어느 가족 목록에 추가할지 선택하면 상품 정보가 자동으로 채워진 채 등록됩니다.
  3. 목록에서 항목의 요청 버튼을 누르면 가족에게 구매 요청 문자를 보낼 수 있습니다.

Minseo9

버스 도착 알림

6900번 버스 도착을 실시간으로 알려주는 앱

주요 기능

  • 정류장(동천동현대홈타운2차아파트) 기준 6900번 버스(잠실종합운동장 방향) 도착 정보를 30초마다 조회
  • 남은 시간(분) · 남은 정류장 수 · 빈 좌석 수를 큼직하게 표시, 3분 이내면 경고색으로 강조
  • 1번차/2번차 중 원하는 차량을 선택해 추적 가능
  • 단계별 알림 — 15/10/5/3/1분 전 알림 + 도착 알림, 배터리 최적화 제외 안내

사용법

  1. 앱을 열면 현재 도착 정보가 바로 표시됩니다.
  2. 추적할 차량(1번차/2번차)을 선택합니다.
  3. 알림을 켜두면 버스가 다가올 때 단계별로 알림을 받습니다.

MyCard

카드 사용내역

이번 달 카드 승인 금액을 자동으로 합산

주요 기능

  • 문자(SMS)와 삼성 RCS 알림을 자동으로 분석해 카드 결제/취소 내역 파악
  • 카드(전화번호 발신자 + 카드명)별로 그룹핑해 이번 달 승인 총액을 합산 (취소분은 자동 차감)
  • 홈 화면 위젯으로 앱을 열지 않아도 현재 사용액 확인 가능

사용법

  1. 처음 실행 시 문자 읽기 권한을 허용합니다.
  2. 설정 화면에서 어떤 카드(발신 번호 + 이름)를 추적할지 등록합니다.
  3. 메인 화면 또는 홈 화면 위젯에서 이번 달 카드별 사용액을 확인합니다.

MinseoStore

앱 스토어

이 문서에 있는 모든 앱을 설치/업데이트하는 허브 앱

주요 기능

  • NAS에서 관리 중인 앱 목록을 가져와 카드 형태로 표시
  • 설치된 버전과 스토어 최신 버전을 비교해 업데이트 필요 여부 표시
  • 버튼 하나로 APK 다운로드 → 자동 설치 (진행률 표시)
  • 앱을 길게 눌러 삭제하거나 앱 정보(데이터 삭제 등) 화면으로 이동

사용법

  1. 가장 먼저 설치해야 하는 앱입니다 (다른 앱들의 설치 창구 역할).
  2. 목록에서 원하는 앱의 설치 또는 업데이트 버튼을 누릅니다.
  3. 새로고침 메뉴로 최신 앱 목록을 다시 불러올 수 있습니다.

Minseo11

개발 중 · 아직 미배포

카카오톡 스타일 UI를 입힌 기본 문자(SMS/MMS) 앱

아직 MinseoStore에 올라와 있지 않습니다. 완성되면 이 문서와 스토어에 함께 추가될 예정입니다.

목표 기능 (구현 진행 중)

  • 카카오톡과 비슷한 말풍선 채팅 화면으로 문자/멀티미디어 메시지 주고받기
  • 대화 목록 탭 분리(전체/안읽음/번호있음/번호없음), 대화 보관/복원
  • 대화방 공지(고정 메시지), 사진 모아보기, 채팅방 내부 검색
  • 글자 크기/서체 설정
이 문서는 각 앱의 실제 동작을 확인해 정리한 것으로, 기능이 추가되면 업데이트됩니다.
